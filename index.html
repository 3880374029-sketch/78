📖 操作说明

窍某论坛 · 完整最终版 使用指南（数据存于 Supabase）

1. 打开方式

直接用浏览器打开 index.html 即可使用（推荐 Chrome / Edge 最新版）。页面需联网加载 Supabase、Google 字体、DOMPurify、MathJax、Stripe 等外部资源；若网络不通，顶部会提示加载失败。

数据存储在后端 Supabase，首次使用前请确认数据库已按 supabase_setup.sql 初始化建表，否则登录、发帖等操作会报错。

2. 账号：注册 / 登录 / 退出

点击右上角 「登录」 弹出窗口，有 登录 / 注册 两个页签：

方式说明
邮箱 + 密码注册需填昵称、邮箱、密码（至少 6 位）、确认密码
Google / GitHub社交登录，一键授权

登录后右上角显示头像、昵称，出现 👤 个人中心与退出按钮。未登录可以浏览、搜索帖子，但 发帖、评论、点赞、签到、任务、商城等操作都需要登录。

个人中心（👤）

  • 点击头像可上传头像图片。
  • 可修改昵称（≤30 字）。
  • 查看等级进度条、积分、巧克力、连续签到天数。
  • 查看统计：帖子数、评论数、获赞、关注、粉丝。
  • 「我的帖子」列表可快速回看自己发过的内容。

3. 界面总览

顶部导航栏

元素功能
🔍 搜索框输入关键词按回车搜索帖子
🎨打开主题切换（5 种皮肤）
✏️ 发布展开 / 收起发帖表单
🔔通知面板（被 @、被回复等提醒，带未读数角标）
💬私信面板
登录 / 头像区账号操作

统计栏

实时显示：帖子总数、评论总数、用户总数、今日发帖、我的巧克力、我的积分、我的收藏。

主内容区

  • 版块导航：全部 / 技术 / 生活 / 职业 / 话题，点击筛选对应分类。
  • ➕ 话题：创建新话题（需登录）。
  • 🍫 商城：购买装扮、购买巧克力。
  • ❤️ 收藏：查看我收藏的帖子。
  • 视图切换：📋 列表 / 🔲 网格 两种帖子展示方式。

右侧边栏

  • 🔥 热门：点击热门帖直达。
  • 🏷️ 标签：按标签筛选帖子。
  • 🟢 在线用户：当前在线人数与名单（登录后可见自己的在线状态）。
  • ✅ 签到：每日签到入口。
  • 🍫 积分换巧克力：50 积分兑换 1 块巧克力。
  • 📋 任务：每日任务与积分流水。
  • 🛒 商城：快捷入口。
  • 🎮 玩法中心：排行榜、幸运转盘、成就、签到日历、贪吃蛇、记忆翻牌、石头剪刀布、反应测试。

页脚：关于 / 帮助 / 反馈 / 状态（可提交反馈、查看站点状态）。

4. 发帖

点击顶部 「✏️ 发布」 展开发布表单：

  1. 分类：技术 / 生活 / 职业 / 话题（必选）。
  2. 标题：不超过 100 字。
  3. 内容：支持富文本语法，见下表。
  4. 标签：逗号分隔，例如 前端, React, 教程。
  5. 点击 发布。

内容支持的特殊语法

语法效果
$...$ 或 \(...\)LaTeX 数学公式（页面加载 2 秒后自动渲染）
@用户名提及用户，对方会收到通知
$\colour 文字$彩虹渐变文字
$\big 文字$加大字号
$\glow 文字$发光文字
$\blink 文字$闪烁文字
[#happy] 等表情代码：happy😄 happyn😁 why🤔 sad😢 love❤️ cool😎 angry😡 cry😭 laugh😂 wow😮
😊 按钮打开 emoji 选择面板，插入表情
换行自动转成 <br> 换行显示

帖子内容经 DOMPurify 过滤，安全显示。

5. 浏览与搜索

  • 分类筛选：点击版块按钮（全部/技术/生活/职业/话题）。
  • 搜索：顶部搜索框回车，按标题/内容关键词检索。
  • 标签：点击帖子下方的 #标签，或侧边栏「标签」，按标签筛选。
  • 话题：点击「话题」分类查看话题帖；「➕ 话题」可创建新话题。
  • 帖子详情：点击帖子卡片进入，自动 +1 浏览量。
  • 返回：详情页左上角「← 返回列表」。
  • 右键菜单：在帖子卡片上点右键 →「回应此帖」，评论框会自动带上「回复：」前缀。

6. 互动操作

在帖子详情页可对帖子执行：

操作说明
❤️ 点赞喜欢此帖（计入每日任务「点赞」）
👍 推荐推荐此帖（计入每日任务「推荐」）
👎 踩不赞同
🍫 投巧克力把巧克力送给作者（不能投给自己）
❤️/🤍 收藏收藏 / 取消收藏，收藏夹在顶部「❤️ 收藏」查看
➕ 关注 / ✅ 已关注关注或取关作者
💬 私信快速给作者发私信
✏️ 编辑 / 🗑️ 删除仅作者本人可见，删除不可恢复

评论

  • 登录后可在底部输入框写评论、发表。
  • 评论旁 😊 按钮可插入 emoji。
  • 每条评论可以点 ❤️/🤍 点赞。
  • 未登录时提示「请登录后评论」。

7. 积分系统 ⭐

积分是网站的核心货币，可用来抽奖、兑换巧克力等。

积分获取方式

方式奖励
✅ 每日签到基础 +5，连续签到另有阶梯奖励
📝 发布帖子每日任务，+3
💬 评论（2 条）每日任务，+2
❤️ 点赞（3 次）每日任务，+1
👍 推荐每日任务，+2
🎡 幸运转盘抽中即得（消耗 20 积分/次）
🏅 成就解锁成就获得成就积分
🐍 贪吃蛇 / 🧠 记忆翻牌登录状态打出好成绩奖励积分
⭐ 积分流水「任务」面板中可查看每笔积分进出记录

积分消费

  • 🍫 积分换巧克力：50 积分 = 1 块。
  • 🎡 幸运转盘：20 积分抽一次。

10. 任务 / 成就 / 签到日历

📋 每日任务

每天刷新，完成任务自动累计进度并发放积分：发布帖子 ×1、评论 ×2、点赞 ×3、推荐 ×1、签到 ×1。

🏅 成就墙

  • 完成各类行为解锁成就。
  • 顶部显示「已解锁 X / Y」「成就积分」，解锁进度全站可见。

📅 签到日历

  • 每天可签到一次，重复签到会提示「今天已签到」。
  • 连续签到不断档，7 天一个周期，奖励阶梯：+2 → +2 → +4 → +2 → +8 → +16 →（第 7 天）+16 积分 + 🍫1。
  • 日历中用 ✓ 标记已签、● 标记今天。
