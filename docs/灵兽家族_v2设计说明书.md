## 二、与原 `index.html` 的兼容策略（重要）

现有 `index.html` 是一份 **~9,360 行、约 0.5MB 的单文件论坛**：2480 行内联 CSS（含 5 套主题变量）、5900 行内联 JS（Supabase 后端）。

### 2.1 冲突风险评估

| 冲突面 | 风险 | 处理方式 |
| --- | --- | --- |
| CSS 类名 | 论坛已有 `.btn / .card / .modal / .tag / .grid / .field` 等通用类；游戏样式同名会互相污染 | **游戏整体运行在 iframe 内**，样式天然隔离 |
| CSS 变量 | 论坛在 `:root` 定义 `--bg-primary / --accent / --bg-grad …` 等；游戏同名变量会串味 | iframe 隔离；海报样式变量全部收在 `.qm-poster` 内部，**不写 `:root`** |
| 全局 JS | 论坛有 `openModal / confirmOk / navigateTo` 等全局函数；游戏同名会覆盖 | iframe 独立 window；海报模块只用 `QMPoster*` 命名空间 |
| 布局 | 论坛是 `header → forum-stats → main-layout → footer` 结构 | 海报以**独立块**插入 `forum-stats` 与 `main-layout` 之间，不参与任何既有布局计算 |
| 首屏性能 | 论坛已加载 Supabase / DOMPurify / Stripe / MathJax | 游戏 iframe **首次点击才创建 `src`**；海报仅 3 个小型 JS（合计 < 30KB）+ 1 个 CSS |

### 2.2 对 `index.html` 的全部改动（共 4 处，纯新增，零删除）

| # | 位置 | 改动 |
| --- | --- | --- |
| 1 | `</head>` 前 | 新增 `<link rel="stylesheet" href="assets/css/poster.css">` |
| 2 | `forum-stats` 之后 | 新增 `<div id="qmPosterMount" class="qm-on-dark"></div>` 海报挂载点 |
| 3 | `</body>` 前 | 新增 3 个 `<script src>`（海报插画 / 海报组件 / 论坛接入层） |
| 4 | 运行时（由 JS 注入） | 侧栏「玩法中心」网格首位插入「🐯 灵兽家族」入口；顶部导航追加同名入口 |

> 既有 HTML 结构、CSS 规则、JS 函数、Supabase 逻辑**一行未改**。
> 如需回滚：删除上述 3 处标记（均有 `v2 新增` 注释）即可。

### 3.3 尺寸适配（响应式方案）

| 断点 | 版式 | 容器高度 | 文案区宽度 |
| --- | --- | --- | --- |
| ≥ 1600px 超宽屏 | 左文右图 | `clamp(206px, 28vw, 392px)` | 固定 700px（防止文案被拉散） |
| 1024–1599px 桌面 | 左文右图 | `clamp(206px, 28vw, 392px)` | ≤ `min(58%, 640px)` |
| 640–1023px 平板 | 左文右图（收窄） | `clamp(236px, 33vw, 372px)` | ≤ `min(66%, 560px)` |
| ≤ 639px 手机 | **图文叠压**（插画在上、文案在下） | `clamp(330px, 96vw, 470px)` | 100%，按钮拉伸等宽 |
| ≤ 380px 超窄屏 | 极限压缩 | 同上 | 隐藏 slogan，保留标题+按钮 |

- 所有字号使用 `clamp()` **连续缩放**，避免断点跳变造成的突兀感；
- 移动端支持**左右滑动切换**，桌面端支持**方向键**与**鼠标悬停**；
- 插画使用 `preserveAspectRatio="xMidYMid slice"`，任何容器比例都铺满不变形。

### 3.4 清晰度与性能

| 指标 | 做法 | 结果 |
| --- | --- | --- |
| 清晰度 | 插画为**纯 SVG 矢量路径**（山峦/云带/日轮/三灵兽图腾/百层塔/九头相柳/战旗） | 任意 DPI、任意缩放级别都锐利，无锯齿 |
| 网络请求 | 插画内联在 JS 中直接输出字符串，**不产生任何图片请求** | 额外请求数 = 0 |
| 体积 | 3 张海报插画 + 组件 ≈ 28KB（gzip 后约 9KB） | 对首屏影响 < 0.5% |
| 布局位移（CLS） | 容器高度由 CSS `clamp()` 完全决定，与素材加载无关 | **CLS = 0** |
| 渲染开销 | `contain: paint` 限制重绘范围；`will-change: opacity` 只加在淡入淡出层 | 无长任务 |
| 节能 | 切到后台标签页、鼠标悬停、键盘聚焦时**自动暂停**轮播；`prefers-reduced-motion` 下关闭动画 | 符合无障碍与省电要求 |
| 可访问性 | 文案是真实 DOM 文本（可选中/可检索）；每个幻灯片有 `aria-label`、`aria-roledescription`；圆点为 `role="tablist"` | 屏幕阅读器可读 |

### 3.5 自动换肤

论坛有 5 套主题（默认暗紫、浅色、粉、赛博、森林）。海报脚本通过读取 `--bg-primary` 计算亮度，
自动为海报加上 `.qm-on-dark`（深色描边环）或移除，并用 `MutationObserver` 监听主题切换实时更新。

## 四、★ 新增玩法①：神兽试炼塔

**定位**：给玩家一个不依赖家族、随时可推进的长期垂直目标，并作为**兽魂碎片/破境石**的主要产地。

| 项目 | 规则 |
| --- | --- |
| 入口 | 主城快捷卡 / 征战页「🗼 试炼塔」标签 / 海报第 2 张 |
| 层数 | 1 → 100 层，层数进度**永久保留**（长期目标） |
| 每日次数 | 3 次免费；可用 60 灵玉购买额外次数，**次数每日刷新** |
| 敌人强度 | 等级 = `6 + 层数 × 2.15`；1–9 层 2 只，10 层起 3 只 |
| 首领层 | 每 5 层，敌人全属性 ×1.25，命名「塔灵·××」 |
| 失败惩罚 | **不扣层数、不扣次数以外的资源**，可反复尝试 |
| 奖励 | 金币 `300+层×145`；兽魂碎片（首领层 `12+层/5×3`，普通层 `4+层/10`）；家族贡献 `30+层×8`；每 5 层额外破境石；每 10 层额外技能秘典；每 25 层额外灵玉 |
| 首通奖励 | 额外 80 灵玉 + 20 兽魂碎片，并写入「动向」播报 |
| 排行榜 | 新增 **「🗼 试炼塔榜」**，按最高到达层数排序（已并入排行榜页第 5 个标签） |

**交互流程**：
`征战 → 试炼塔` → 看到「当前层 / 本层守关预览 / 本层奖励」→ 点【挑战第 N 层】→ 播放战斗动画 →
胜利则层数 +1、弹出奖励提示、排行榜即时刷新 → 连续挑战直到次数用完 → 可花灵玉买次数。

## 五、★ 新增玩法②：灵兽羁绊

**定位**：把「三系灵兽」从三条独立养成线，变成**需要动脑搭配的编队博弈**，直接串联宠物系统与战斗系统。

### 5.1 六组羁绊

| 羁绊 | 品质 | 触发条件 | 效果 |
| --- | --- | --- | --- |
| ☯️ 天地人三才阵 | SSR | 白虎 + 黄牛 + 鸡 **同时上阵** | 全队 生命 +12%、攻击 +12%、防御 +10%、暴击 +5% |
| 🔱 三兽同心 | UR | 上阵 3 只且**物种互不重复** | 全队 治疗 +15%、速度 +8% |
| ⛰️ 金石相生 | SR | 白虎 + 黄牛 | 全队 暴击率 +8% |
| 🌳 土木相济 | SR | 黄牛 + 鸡 | 全队 受到伤害 −10% |
| ⚡ 金木相克 | SR | 白虎 + 鸡 | 全队 暴击伤害 +20%，但**自身承受伤害 +5%**（有代价） |
| ♊ 双生同源 | R | 队内出现 **2 只同种**灵兽 | 该灵兽 攻击 +6% |

> 【三才阵】与【三兽同心】可**同时激活**，是全队收益最高的组合；
> 【金木相克】是高爆发+反噬的风险博弈，适合速攻流。

### 5.2 交互方式

`灵兽 → ☯️ 羁绊` 标签页：
- 左栏 **羁绊图录**：每组显示徽章、品质、效果标签、激活状态、以及**未激活时提示还缺哪只灵兽**（如「还缺：黄牛」）；
- 右栏 **当前队伍** + **羁绊总加成**（实时数值标签，如 `生命 +12%` `暴击率 +5%`）；
- 【✨ 一键推荐编队】按钮：枚举所拥有灵兽的全部组合（物种数 ≤ 3，组合规模极小），
  按「激活羁绊数 × 1000 + 攻击权重 × 2000 + 生命权重 × 1500 + 战力」打分，选出最优编队并**自动上阵**。

### 5.3 生效范围（工程细节）

- 羁绊加成同时计入 **面板属性**、**战力数字**、**排行榜战力**、**战斗实际结算**；
- 羁绊**只作用于出战队伍内的灵兽**——替补席灵兽不吃加成（避免用羁绊虚刷战力）；
- 战斗中**只有己方享受己方羁绊**，敌方 NPC 队伍不继承玩家羁绊；
- 实现方式：以装饰器包装 `Store.computeStats` / `powerOf` / `teamPower`，**不修改任何原有函数体**。

## 六、★ 新增玩法③：灵兽繁育

**定位**：给重复获得的灵兽一条「再利用」路径，同时提供**低概率博取高星**的兴奋点。

| 项目 | 规则 |
| --- | --- |
| 入口 | 主城快捷卡 / 灵兽页「🥚 繁育」标签 |
| 双亲门槛 | 两只灵兽均需 **≥ Lv.30** |
| 次数 | 每日 **1 次免费**；超出后每次消耗 **300 灵玉** |
| 物种继承 | 42% 随 A、42% 随 B、**16% 基因突变**（从三系中随机） |
| 星级继承 | 基础 = `floor((A★ + B★) / 2)`；有 **28% 概率额外 +1 星**；受该物种品质上限约束（R 3★ / SR 4★ / SSR·UR 5★） |
| 子代起点 | Lv.5 起 |
| 天赋点数 | 上限 ≈ `min(18, floor((LvA + LvB) / 12))`，随机分配到 生命/攻击/防御/速度 四项 |
| 双亲代价 | **不会消失**，但各自亲密度 −10（亲密度影响全属性百分比，形成取舍） |

**交互方式**：
`灵兽 → 🥚 繁育` → 点选两只符合等级的灵兽（卡片高亮 ✅）→ 右侧「繁育台」实时显示
**⚡ 预计星级区间 / 物种概率 / 子代等级 / 天赋点数上限** → 点【🧬 开始孵化】→
弹出孵化结果卡（灵兽形象、星级、天赋点数、血脉来源）→ 新灵兽自动进入「我的灵兽」。

## 八、核心系统设计（v1 主体，供参考）

### 8.1 三系灵兽

| 灵兽 | 定位 | 品质 | 元素 | 核心特色 |
| --- | --- | --- | --- | --- |
| 🐯 **白虎** · 裂风之牙 | 输出 | SSR | 金 | 单体爆发最高；流血 DoT；残血斩杀（对 <50% 生命额外 +40% 伤害）；被动暴击 +20% / 暴伤 +25% / 击杀回怒 |
| 🐂 **黄牛** · 撼地重犁 | 坦克 | SR | 土 | 全队最高生命与防御；嘲讽+眩晕；260% 攻击护盾+反伤 25%；被动受伤 −18% 且 35% 概率反击 |
| 🐓 **鸡** · 司晨金羽 | 辅助 | R | 木 | 全队治疗与攻击增益；终极技**驱散 + 群体治疗 + 唯一复活**；被动每回合为血量最低队友回血、全队暴伤 +12% |

**属性成长公式**

```
最终属性 = 基础 × (1 + 11.5% × (等级−1)) × (1 + 8% × (星级−1)) × 进化阶段系数 × (1 + 0.15% × 亲密度)
          × 家族等级加成 × 家族科技加成 × 羁绊加成
```

**伤害公式**

```
伤害 = 攻击 × 技能系数 × (1 + 6% × (技能等级−1)) × 防御常数/(防御常数+目标防御)
       × (暴击 ? 1 + 暴击伤害 : 1) × (1 ± 6% 浮动) × (1 − 目标减伤)
防御常数 = 420 + 6 × 攻击方等级
```

### 8.2 战斗系统

- **3v3 回合制自动战斗**，按速度降序行动，30 回合上限（超出按剩余生命百分比判定，差距 <5% 判平局）；
- **怒气系统**：初始 30，自身行动 +20，受击 +10，每回合自然 +8，上限 100；主动技消耗 30/50 怒气并有 2–3 回合冷却；终极技消耗 100；
- **增益/减益**：攻击/防御/速度升降、命中降低、流血（DoT）、眩晕（跳过行动）、护盾（吸收）、反伤、嘲讽（强制单体指向）；
- **AI 决策**：有终极技优先释放；治疗类技能仅在队友受伤 >25% 或有阵亡时才使用（不浪费）；
- 引擎为**纯函数式模拟**，输出完整 `timeline` 事件流，前端按时间轴播放动画（支持 1× / 2× / 4× / 跳过）。

### 8.3 家族系统

| 模块 | 规则 |
| --- | --- |
| 创建 | 消耗 5,000 金币；名称 2–8 字；可选徽章；写公告 |
| 职位 | 族长 / 副族长 / 长老 / 精英 / 成员，权限表区分「踢人、发起家族战、结盟、改公告」 |
| 等级 | 1–10 级；家族经验来自捐献与家族战；每级 +1.5% 全族灵兽全属性 |
| 人数 | 20 + (等级−1) × 2 |
| 资金 | 捐献累积，用于家族科技 |
