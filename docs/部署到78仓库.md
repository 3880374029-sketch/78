## 路线 C：git 命令行（最完整，含自动打补丁）

本机已装 git + Node 的话，**在项目根目录**（`qmhub-pet-system\`）执行：

```bash
# 1) 克隆 78 仓库到临时目录
git clone https://github.com/3880374029-sketch/78.git _repo78

# 2) 把新增目录拷进去（不要覆盖 index.html，避免冲掉仓库上的版本）
xcopy /E /I /Y assets  _repo78\assets
xcopy /E /I /Y docs    _repo78\docs
xcopy /E /I /Y backend _repo78\backend

# 3) 给「仓库里的」index.html 打补丁（幂等，自动备份成 index.html.bak）
node tools/patch-index.js _repo78/index.html

# 4) 提交并推送
cd _repo78
git add -A
git commit -m "feat: 接入灵兽家族（宠物系统+家族系统+宣传海报）"
git push origin main
```

回滚：

```bash
node tools/patch-index.js _repo78/index.html --restore   # 还原 index.html
git checkout -- .                                        # 放弃所有本地改动
```

> Windows 下用 PowerShell / Git Bash 时，`xcopy` 换成
> `cp -r assets docs backend _repo78/` 即可。

**为什么游戏放在 iframe 里**：`index.html` 是 2,480 行内联 CSS + 5,900 行内联 JS 的单文件应用，
`.btn / .card / .modal / .tag` 等通用类名和 `:root` 变量与游戏样式天然冲突。
iframe 提供完整的 CSS/JS 作用域隔离 —— 论坛零回归风险；同时**首次点击才创建 src**，
不拖慢论坛首屏加载。

## 常见问题

**Q：海报没出现？**
按 F12 看 Console / Network：
- `assets/js/qm-boot.js` 404 → 说明 B1 的上传没成功，或 index.html 不在仓库根目录
- `assets/css/poster.css` 404 → 只传了 js 没传 css
- `CNAME` 存在时 GitHub Pages 会用自定义域名，记得清 CDN 缓存（Ctrl+F5 强刷）

**Q：游戏点开是空白？**
打开 <https://qmhub.cc.cd/assets/petworld.html> 单独访问，看 Console 报错。
按 A 路线或 C 路线部署不会有缺文件问题；B 路线容易漏传个别文件。

**Q：想改海报文案？**
改 `assets/js/ui/poster.js` 里的 `QMPoster.DEFAULT_POSTERS` 数组即可，不用碰其它文件。

**Q：想彻底回滚？**
删掉 `index.html` 里那 1 行 `<script>`，再删除 `assets/` 目录，就回到部署前状态。
